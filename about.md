Hi, I'm **Mykhailo Markhain**, a Solutions Architect and Senior Software Engineer at Amazon, based in San Diego. I've spent 11+ years turning complex systems into reliable products, from distributed commerce platforms to cloud security automation and, lately, production agentic AI.

This blog is where I write down what I build and learn. It's practical and hands-on, and every post comes with working code you can run.

## What I work on

- **AWS security automation.** I'm a core engineer on public AWS Solutions: [Automated Security Response on AWS](https://aws.amazon.com/solutions/implementations/automated-security-response-on-aws/), Security Automations for AWS WAF, and Account Assessment for AWS Organizations. The work covers multi-account CDK deployments, EventBridge-driven incident workflows, and bot protection.
- **Agentic AI in production.** I design multi-agent systems with tool calling, planner–executor loops, and human approval gates. I build LLM workflows on Amazon Bedrock with Claude, plus grounded retrieval with Knowledge Bases and Kendra.
- **LLMOps and evaluation.** I set up golden datasets, LLM-as-judge scoring, hallucination and regression tests, and quality gates that a model has to pass before it reaches production.
- **Distributed systems.** I build event-driven, multi-tenant platforms in Java, Python, TypeScript, and Rust.

## Before Amazon

I led engineering teams and built commerce and fintech platforms:

- **Total Wine & More:** Java engineering manager.
- **CoinFlip:** technical lead for wallet services and event-driven microservices.
- **Market Group:** software engineering manager.
- **Earlier:** e-commerce and web platforms at Everything5Pounds and TemplateMonster.
